# DC6 Viewer
创建一个用来查看DC6文件的工具。可独立运行，也可以被父目录的程序调用，用来显示DC6图片。

## 界面
1. 提供打开，关闭，另存为, 导出BMP功能。
2. 左侧显示DC6当前帧的信息: 宽度，高度，X偏移, Y偏移。
3. 左侧同时可以修改DC6的palettes. 可使用的palettes在pal目录里面。
4. 右侧显示选中帧的图片, 占大部分面积。
5. 右侧下方水平显示每一帧的缩略图和索引（从0开始）。如果帧数太多，需要按需显示水平滚动条。


## 导出
导出时，需要用户指定: 起始帧，帧数， 每个图片行帧数，行数, 图片名字。
默认起始帧是0，帧数为DC6所有帧。行帧数1， 行数1. 图片名字默认用dc6文件名(去掉.dc6)。
举例：假设起始帧数0， 帧数32，行帧数2， 行数2。 一共导出8个图片，每个图片占用4帧。导出图片为name-00.bmp~name-07.bmp.
如果导出图片只有一张，用name.bmp

## 帧编辑（右键菜单）
帧列表（左下的表格）和下方缩略图栏都支持右键。

- 在某一帧上右键：可「在此帧之前 / 之后插入图像」「替换此帧图像」「删除此帧」
  「导出此帧」「设置 X/Y 偏移」。
- 在空白处右键：在末尾插入图像。还没有打开 DC6 时可右键新建空白 DC6。
- 插入图片时如果宽或高超过 256，按「每行帧数」自动拆成多帧（拆分顺序见根目录 design.md）。
- 替换只允许不超过 256x256 的单帧图片，超尺寸直接报错；替换会保留原帧的 X/Y 偏移。
- 导出此帧支持 BMP（索引色，保留调色板索引）与 PNG/JPG（0 号色透明）。

## 调色板的可用颜色
`pal/*.pal` 都是 768 字节 = 256 个 BGR 条目（`palette_rgb()` 已按 BGR 读取），
但**可跨 Act 通用的颜色只有 224 个**：

| 索引 | 用途 |
|---|---|
| 0 | 透明色（与 RGB 值无关，由索引决定） |
| 1..224 | 224 个各 Act 一致的通用色 |
| 225..254 | Act 专属色；`units.pal` 里整段留空为黑，即未使用 |
| 255 | 纯白 |

因此导入图像时**所有分支都只生成 0..224 号索引**：`225..254` 在 `units.pal` 下是黑，
换到 `act1` 等调色板就变成杂色；`255` 纯白虽然通用，但索引超过 224，同样不参与导入量化。
240 不是本套调色板的规则。显示与 BMP 导出仍使用完整 256 项调色板（忠实呈现帧数据）。

## 图像导入的透明处理
「插入图像 / 替换图像」对话框提供「保留黑色：仅透明像素使用透明色 (pal 0)」选项，默认关闭。
无论是否勾选，颜色量化范围都固定为 `0..224`，没有可绕过上限的开关。

- 默认（历史行为）：只按 RGB 量化。0 号色本身是黑色，因此纯黑像素会被当成透明背景。
- 勾选后：
  - 只有源图 alpha=0 的像素写 0 号色（透明），且不参与抖动误差扩散，避免透明边缘出现色晕；
  - 其余可见像素（含纯黑、半透明）只在 1..224 里找最近色，黑色不再被挖空。
- 该选项对插入（含大图拆帧）和替换同样生效，适合带透明背景、以黑色线条绘制的 PNG 图标。
- 代价：纯白会改用 1..224 里最接近的浅色（224 号附近），不再使用 255 号纯白。
- 该选项会记住：点「确定」后写入 QSettings（`import/preserve_black`），下次打开导入
  对话框自动预填；点「取消」不改变偏好。插入与替换共用同一个值。

## 切换文件时的未保存修改
新建、打开文件、打开目录、左侧文件列表切换，以及主程序在 MPQ 里双击另一个 DC6
（都经过 `load_data`），凡是当前文档带 `*` 修改标记，都会先弹出「是 / 否 / 取消」：

- **是**：先保存当前文件再切换；保存失败（或另存为被取消）则不切换，避免丢改动。
- **否**：放弃改动并切换。
- **取消**：保持当前文档与左侧列表高亮不变。

从 MPQ 内部打开的路径不是磁盘文件，`_source_is_virtual` 为真，此时「保存」与
「是」都改为「另存为」，让用户指定真实文件，而不是往归档内的虚拟路径写盘。

## X/Y 偏移
- 双击帧表格的 X偏移 / Y偏移 单元格可直接改数值（有符号 32 位，允许负数）。
- 也可以右键「设置 X/Y 偏移」用对话框同时修改两个值。
- 修改后的偏移在保存 DC6 时写进块头。

## 模块划分
- `dc6/model.py`：DC6 解析/序列化、调色板、抖动、切片、BMP 编码（无界面依赖）。
- `dc6/frame_ops.py`：插入/删除/替换/偏移/单帧导出等纯逻辑操作。
- `dc6/dc6_viewer.py`：窗口、菜单、对话框；为兼容旧调用仍再导出模型层符号。

## 运行
这个模块可独立运行，也可以由主界面调用。主界面调用时，直接传进来DC6的内存数据。
